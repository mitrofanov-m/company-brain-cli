Company Brain CLI 0.1.1 adds streaming binary file transfers up to
1,000,000,000 bytes. Requires Python 3.11+; no runtime dependencies.
Binary transfers require Company Brain API 0.2.2.

- `brain files write PATH LOCAL_FILE --commit` streams the original file bytes.
- `brain files download PATH LOCAL_FILE` verifies SHA-256 and replaces the
  destination atomically only after a successful download.
- Interrupted uploads do not create a staged file. Interrupted or invalid
  downloads preserve the previous destination.
- Stdin text writes retain the existing JSON tool protocol.

Downloads: `brain-0.1.1.pyz`, `company_brain_cli-0.1.1-py3-none-any.whl`,
`company_brain_cli-0.1.1.tar.gz`, and `SHA256SUMS`. This is a GitHub release;
the package is not published to PyPI.

The 17 standalone tests and zipapp version/help checks passed. Compatibility
is tested against the release candidate API, including exact 1 GB upload,
commit, verified download, API/MCP interoperability, authorization and Docker
execution. Logs and publication status are in `docs/verification.md`.

Both the portable zipapp and uv-installed wheel passed all five real
API/MCP/Docker compatibility checks against the Company Brain 0.2.2 candidate.
