First standalone Company Brain CLI release. Requires Python 3.11 or later;
no runtime dependencies. The Company Brain server is deployed separately.

## Downloads

- `brain-0.1.0.pyz`: portable client; run `python3 brain-0.1.0.pyz --help`.
- `company_brain_cli-0.1.0-py3-none-any.whl`: installable `brain` command.
- `company_brain_cli-0.1.0.tar.gz`: source distribution, including tests and build scripts.
- `SHA256SUMS`: checksums for all three files.

Install the downloaded wheel with uv from your workspace:

```sh
mkdir -p .tmp
export TMPDIR="$PWD/.tmp"
export UV_CACHE_DIR="$PWD/.tmp/uv-cache"
export UV_PYTHON_DOWNLOADS=never
uv venv --no-managed-python --python python3 .venv
uv pip install --python .venv/bin/python --no-index ./company_brain_cli-0.1.0-py3-none-any.whl
.venv/bin/brain --version
```

## Included

Workspace list/read/search/history; session start/resume/commit/close; file
write/delete; tool discovery and calls; server-side script execution; HTTPS and
credential redirect protection; workspace-local configuration. The import
package is `brain_cli`, separate from the platform's `company_brain` package.

## Verification

Tested on macOS arm64 with CPython 3.14.7 and uv 0.11.3. The standalone suite
passed all 14 tests. The installed wheel and the portable zipapp each passed
5 real Company Brain API/MCP/Docker checks, including permissions, session
isolation, successful script commit and rollback on script failure. The server
used Company Brain 0.2.1. Other supported Python versions have not yet been tested.

This GitHub release does not publish the package to PyPI.
